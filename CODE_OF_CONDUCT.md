# Code of Conduct & Community Guidelines

## Project Status & Contribution Scope

**`imgui-android`** is a standalone, personal open-source port independently maintained by [@git-drs](https://github.com/git-drs).

- **Contributions & Pull Requests**: Contributions, bug fixes, and improvements are welcome! If you plan to make major changes, please open an issue first to discuss what you'd like to change.
- **Pull Request Standards**: Ensure all code compiles cleanly with `bash build.sh` on Android ARM64 without breaking existing JNI bindings or introducing desktop dependencies.
- **Bug Reports & Inquiries**: You are welcome to open GitHub Issues for bug reports, build troubleshooting, or compatibility questions. Please include relevant logs, device specs, and reproduction steps.
- **Maintenance Expectations**: Maintenance, reviews, and issue replies are handled by [@git-drs](https://github.com/git-drs) based on personal availability and discretion.

---

## Community Standards

When participating in this project's GitHub Issues or discussions, please adhere to the following standards:

### Expected Behavior
- **Be Respectful**: Treat everyone with courtesy and respect regardless of skill level or background.
- **Be Constructive**: Provide clear, reproducible details when reporting issues (e.g. device model, Android version, build error logs).
- **Stay on Topic**: Keep discussions relevant to `imgui-android`, Android compilation, and runtime compatibility.

### Unacceptable Behavior
- Harassment, insults, derogatory comments, or personal attacks.
- Trolling, disruptive arguments, or spamming.
- Demanding features, deadlines, or unsolicited commercial promotion.

---

## Maintainer Responsibility & Enforcement

The maintainer reserves the right to:
- Close or lock issues, discussions, or comments that violate these guidelines or become non-constructive.
- Block accounts that engage in persistent harassment, abuse, or spam.

If you observe unacceptable behavior, please report it via the GitHub Issue moderation tools or open an inquiry on the repository.
